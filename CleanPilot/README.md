# CleanPilot 清源

可运行的 AI 存储治理系统：扫描本地文件夹，按 R0-R3 分级识别可清理内容，清理前先移入回收站，保留期内可随时恢复。

零第三方依赖，仅使用 Python 标准库（Python 3.8+）。

## 启动

```bash
# 方式一：双击 start.bat（Windows，自带演示数据）
# 方式二：命令行
python app.py --demo      # 首次体验，自动创建演示设备
python app.py             # 常规启动
python app.py --port 9000 # 指定端口
```

启动后访问：

- 顾客端：<http://127.0.0.1:8080/>
- 管理后台：<http://127.0.0.1:8080/admin.html>

| 账号 | 密码 | 角色 |
| --- | --- | --- |
| demo | user123 | 普通用户（含演示设备） |
| admin | admin123 | 管理员 |

## 功能

- **设备接入**：添加任意本地文件夹作为扫描设备，可随时切换
- **智能扫描**：遍历文件、按大小分组做 SHA-256 重复检测、R0-R3 风险分级
- **清理方案**：勾选文件生成方案，R2 项必须二次确认后才可执行
- **回收站**：清理文件移入 `.cleanpilot/quarantine`，支持恢复、永久删除、清空
- **清理报告**：记录每次任务的成功/失败明细与释放空间
- **AI 助手**：分析存储健康、按类别给出清理建议，支持对话式问答
- **管理后台**：多设备总览、策略配置（保留天数 / 风险上限 / 保护路径）、审计日志

## 风险分级

| 等级 | 含义 | 处理方式 |
| --- | --- | --- |
| R0 | 缓存、临时文件、空文件 | 默认可安全清理 |
| R1 | 过期安装包、重复文件、旧下载、截图 | 默认选中 |
| R2 | 大文件、压缩包、下载文档 | 需勾选确认 |
| R3 | 相册、程序目录、保护清单 | 永不清理 |

## 说明

- 扫描与清理都在本机完成，不会上传文件内容。
- 清理是“移动到回收站”而不是直接删除；清空回收站才会真正释放磁盘空间。
- 数据库与演示目录都在 `data/` 下，删除该目录即可重置所有数据。
